# gtalent-IT01557-2606

Every Java file declares a `package` matching its directory, so compile and run
from the project root using the fully-qualified class name.

### compile the source java code
```console
>cd /path/to/project/root
>javac -d bin phase01basic/oop/lesson06/Runner.java
```

### execute the class file
```console
>cd /path/to/project/root
>java -cp bin phase01basic.oop.lesson06.Runner
```
